为什么选择 sensitive-lite？

专为低配置服务器优化，减少 42% 内存占用，无锁并发保障高吞吐。

🧠

超低内存占用

加载 10 万敏感词仅需 ~40MB 运行时内存，较传统 map DFA 实现节省 42%。256MB 可用内存即可稳定运行 10 并发无 OOM。

⚡

无锁高并发

纯 DFA 匹配引擎采用双数组节点结构，100 并发下 FindAll 达 28.5 万 ops/s。Contains 快速判断高达 23.8 万 ops/s。

🛡

14 种反清洗识别

覆盖零宽字符、形近字替换、同音字替换、全角半角变体、西里尔/希腊同形字母、Emoji 干扰、Leet Speak、CJK 重复压缩等全方位反制策略。

🔒

生产级容灾机制

内置三级降级策略：基于可用内存的自动降级、手动降级恢复、匹配耗时告警。降级后自动回退到纯精确匹配，杜绝服务雪崩。

12 项功能选项

5 分钟快速接入

Go 1.21+ 即可运行，一行命令安装，一行代码创建过滤器。

go get github.com/sensitive-lite/sensitive-lite

Go 
package main

import (
    "fmt"
    sensitive "github.com/sensitive-lite/sensitive-lite"
)

func main() {
    // 1. 准备自定义敏感词库（组件不内置任何词库，由开发者自行维护）
    words := []string{"敏感词", "违规", "广告"}

    // 2. 创建过滤器（反清洗识别默认开启，无需额外配置）
    filter := sensitive.New(words)

    // 3. 查找所有敏感词（含反清洗识别，自动标准化文本）
    matches := filter.FindAll("敏 感 词 检测")
    for _, m := range matches {
        fmt.Printf("敏感词: %s, 位置: [%d, %d), 类型: %s\n",
            m.Word, m.Start, m.End, m.Type)
    }

    // 4. 替换敏感词为 ***
    result := filter.Replace("这是一条包含敏感词的内容")
    fmt.Println(result.Text) // 这是一条包含***的内容
}
